# 专利与技术秘密档案管理服务

这是一个面向研发机构、法务部门和保密办公室的模块化后端，集中管理专利交底资料、技术秘密载体、移交批次、受控副本签发、查阅借阅、对外披露、归还、合规处置、载体盘点、版本与载体来源、密级库位、泄密事件、登录权限、审计以及可恢复后台任务。项目使用 FastAPI 与 SQLite，所有运行数据保存在单个本地数据库文件中，不依赖另行部署的数据库、缓存或消息队列。

## 已有能力

- 身份与权限：支持引导管理员、登录、会话、用户、角色和细粒度权限。
- 批次与二维码：移交批次保存项目、数量和稳定二维码载荷。
- 档案登记：登记专利交底、工艺文档、源代码介质等资产，保存密级库位和生命周期状态。
- 受控副本签发：一次事务内扣减来源载体、创建副本、记录损耗和版本来源事件。
- 查阅借阅归还：保存查阅用途、到期时间、部分归还和最终归还状态。
- 对外披露登记：使用幂等键登记合作方、披露范围和载体消耗，防止重复请求二次扣减。
- 位置脱敏：普通权限只能看到受限库位的替代码，授权人员可查看精确位置。
- 双人审批：合规处置、敏感库位解密等高风险操作要求申请人与审批人分离，并累计不同审批人的决定。
- 泄密事件追踪：事件可以关联档案或移交批次，保存严重度、调查状态和处置结果。
- 专利家族关系：导入多国申请成员，维护优先权、继续申请、分案、部分继续、国家阶段等关系；关系类型校验、成环检测、优先权日沿确定性拓扑继承；成员合并前提供冲突预演（阻断技术秘密并入公开件），撤销前提供影响查询（优先权日变化、家族分裂）。
- 家族变更审核：加边、合并、撤销均以提案进入双人审批，申请人回避；执行期再次校验并用保存点隔离失败，审批决定与失败原因留痕。
- 家族审计与一致性：重复导入保持原成员；家族汇总只统计活跃关系，撤销/取代边单独排除留痕；拓扑顺序与审计顺序在服务重启后保持确定。
- 审计与任务：关键身份及业务操作留痕，后台任务支持去重、领取与完成。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/archives.db`，可用 `ARCHIVE_DATABASE_PATH` 指定其他路径。

## 初始化与完整性检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 测试

```bash
python -m pytest
```

## 编译检查

```bash
python -m compileall -q app tests
```

## API 冒烟

```bash
python -m app.cli smoke
```

## 专利家族接口（前缀 `/api/patent-families`）

| 方法与路径 | 说明 |
| --- | --- |
| `POST /applications` | 导入申请成员；同辖区+申请号重复导入返回原成员（`replayed=true`） |
| `PATCH /applications/{id}` | 补录状态、公开日、秘密资产标记等（已公开件禁止标为秘密资产） |
| `GET /applications/{id}` | 申请详情、有效优先权日、全部关系与家族拓扑 |
| `POST /changes/links` | 提交建立关系提案（含成环检测与优先权日变化预演） |
| `POST /merge-preview` | 仅预演成员合并冲突与边归并影响，不产生提案 |
| `POST /changes/merges` | 提交成员合并提案；存在阻断性冲突（秘密并入公开）时拒绝 |
| `POST /changes/revocations` | 提交撤销关系提案（携带撤销影响预演） |
| `GET /links/{id}/impact` | 查询撤销某关系后的优先权日变化与家族分裂情况 |
| `POST /changes/{id}/decisions` | 双人审批（申请人回避、同一人不可重复表决），通过后生效 |
| `GET /changes/{id}`、`GET /changes/pending` | 提案详情与待审列表 |
| `GET /{family_id}` | 家族汇总：成员、活跃关系、排除关系、状态计数、拓扑序 |
| `GET /{family_id}/timeline` | 家族事件流，按自增 id 给出确定的审计顺序 |
